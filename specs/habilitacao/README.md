# Habilitação — Pacote de Documentos para Licitações

Esta pasta contém os **modelos prontos** e a **checklist prática** para habilitar a empresa nas licitações TR 027/2021 e Cotação 68/2025. Preencha os campos entre `[COLCHETES]` com os dados da empresa e do cliente.

## Arquivos

- `modelo-atestado-experiencia.md` — modelo de atestado de experiência em saúde (para clientes assinarem).
- `modelo-carta-case-hospital.md` — modelo de carta/case de sucesso do Hospital Santa Maria.
- `modelo-declaracoes.md` — declarações exigidas (não condenação CADE, sem restrição CEIS, etc.).
- `checklist-certidoes.md` — checklist de certidões com onde emitir cada uma.
- `modelo-proposta-cotacao-68.md` — estrutura da proposta comercial da Cotação 68/2025.
- `modelo-cronograma-implantacao.md` — cronograma de implantação e plano de suporte (exigido pela Cotação 68).

## Como usar

1. Preencha os modelos com os dados reais.
2. Colete as assinaturas dos clientes (atestados e carta-case).
3. Emita as certidões (ver `checklist-certidoes.md`).
4. Monte a proposta comercial (ver `modelo-proposta-cotacao-68.md`).
5. Envie dentro dos prazos de cada edital.

> **Importante:** a Cotação 68/2025 também exige qualificação técnica (atestados), qualificação econômico-financeira (balanços) e casos de sucesso. Não é "sem burocracia".
